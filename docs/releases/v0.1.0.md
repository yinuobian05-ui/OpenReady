# OpenReady v0.1.0

Released on GitHub on 2026-08-11. This version has not been published to npm.

## What OpenReady does

OpenReady is an offline, read-only CLI for the final privacy and repository-hygiene review before a Git repository becomes public. It checks the current working tree and Git index for credential risks, personal paths and emails, Git author metadata, risky artifacts, and missing open-source governance files.

It never prints a matched secret value and has zero runtime dependencies.

## First scan

Requirements: Node.js 20 or newer, plus Git for repository metadata checks.

```sh
git clone https://github.com/yinuobian05-ui/OpenReady.git
cd OpenReady
node ./bin/openready.js scan ../your-project
```

For JSON output:

```sh
node ./bin/openready.js scan ../your-project --json
```

## Included

- Text and deterministic JSON output with `BLOCKER`, `WARNING`, and `INFO` findings.
- Exit code `0` for no blocker, `1` for blockers, and `2` for execution or usage errors.
- Relative paths and necessary line numbers without matched values, snippets, hashes, or absolute scan roots.
- Filename and content checks for environment files, private keys, credential classes, secret-like assignments, and high-confidence token shapes.
- Checks for user-home paths, email addresses, Git commit authors, large files, archives, databases, media, logs, backups, and temporary files.
- README, license, security-policy, and contributing-guide checks.
- Bounded inspection of the working tree and every ordinary blob in the current Git index.
- Symlink, binary, unreadable-entry, Gitlink, large-content, and non-Git boundary reporting.
- Git metadata preflight and fail-closed entry, content, finding, output, and command-time limits.

## Known limitations

- Historical Git file blobs are not scanned automatically. Use a maintained, history-aware secret scanner too.
- Ignored, untracked files are outside the Git repository scan set.
- Binary files, archives, databases, media, and Gitlinks are classified but not unpacked or parsed.
- Text files larger than 10 MiB receive filename, type, and size checks only.
- Offline heuristics can miss secrets and can flag non-secrets; credentials are never checked with providers.
- The tool does not replace legal, copyright, license-compatibility, professional secret scanning, or human privacy review.

## Security reports

Do not place secrets or private data in a public issue. Use [GitHub Private Vulnerability Reporting](https://github.com/yinuobian05-ui/OpenReady/security/advisories/new).
