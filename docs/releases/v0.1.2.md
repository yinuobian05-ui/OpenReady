# OpenReady v0.1.2

Released: 2026-08-13

- npm: [@yb5/openready@0.1.2](https://www.npmjs.com/package/@yb5/openready/v/0.1.2)
- GitHub: [v0.1.2](https://github.com/yinuobian05-ui/OpenReady/releases/tag/v0.1.2)

## Purpose

v0.1.2 makes it easier for a real user to provide one privacy-safe observation after a scan without adding telemetry or changing the scanner's JSON contract.

## First scan

Requirements: Node.js 20 or newer, plus Git for repository metadata checks.

Run from a repository you are authorized to check:

```sh
npx --yes @yb5/openready@0.1.2 scan .
```

For JSON output:

```sh
npx --yes @yb5/openready@0.1.2 scan . --json
```

## Changes

- Add the OpenReady launch Discussion link after completed text scans.
- Request only operating-system name, Node.js major version, completion status, the most confusing part, and whether the user would run it again.
- Warn users never to paste scan output or repository data.
- Keep JSON output unchanged for scripts and CI.
- Preserve offline, read-only scans with no telemetry and no printed secret values or Git identities.

## Known limitations

- Historical Git file blobs are not scanned automatically. Use a maintained, history-aware secret scanner too.
- Ignored, untracked files are outside the Git repository scan set.
- Binary files, archives, databases, media, and Gitlinks are classified but not unpacked or parsed.
- Offline heuristics can miss secrets and can flag non-secrets; credentials are never checked with providers.
- OpenReady does not replace legal, copyright, license-compatibility, professional secret scanning, or human privacy review.
