# OpenReady v0.1.1

Released: 2026-08-11

- npm: [@yb5/openready@0.1.1](https://www.npmjs.com/package/@yb5/openready/v/0.1.1)
- GitHub: [v0.1.1](https://github.com/yinuobian05-ui/OpenReady/releases/tag/v0.1.1)

## Purpose

v0.1.1 is OpenReady's first npm distribution, reducing the first scan to one short command. The scanner behavior remains the bounded, offline, read-only v0.1 MVP.

## First scan

Requirements: Node.js 20 or newer, plus Git for repository metadata checks.

Run from the repository to check:

```sh
npx --yes @yb5/openready@0.1.1 scan .
```

For JSON output:

```sh
npx --yes @yb5/openready@0.1.1 scan . --json
```

To run the pinned GitHub source archive instead:

```sh
npx --yes https://github.com/yinuobian05-ui/OpenReady/archive/v0.1.1.tar.gz scan .
```

## Known limitations

- Historical Git file blobs are not scanned automatically. Use a maintained, history-aware secret scanner too.
- Ignored, untracked files are outside the Git repository scan set.
- Binary files, archives, databases, media, and Gitlinks are classified but not unpacked or parsed.
- Offline heuristics can miss secrets and can flag non-secrets; credentials are never checked with providers.
- OpenReady does not replace legal, copyright, license-compatibility, professional secret scanning, or human privacy review.
